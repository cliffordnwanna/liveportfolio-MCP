# Security

To report a vulnerability in the LivePortfolio MCP server or the LivePortfolio service, email **ecotronics.nterprise@gmail.com** with the word "security" in the subject. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and which account or address was involved (use a test account). Do not access, change or delete data that is not yours. We will acknowledge your report and keep you updated.

This repository contains documentation only; the service itself is hosted at https://liveportfolio.site.
